Guide for creating effective Claude Code skills with proper structure, descriptions, and workflows.

- Follows Anthropic's official skill authoring best practices
- Helps design skill structure with progressive disclosure
- Writes effective descriptions for skill discovery
- Avoids common anti-patterns
- Includes validation checklist

**Prerequisites**: Understanding of what the skill should accomplish

**Creates/Updates**:
- `skills/{skill-name}/SKILL.md` - Main skill file
- `skills/{skill-name}/references/` - Supporting documentation (if needed)
- `commands/{skill-name}.md` - Slash command wrapper
