---
description: Implement tasks using TDD with pair collaboration
---

Use the task-development skill to implement a defined task using Test-Driven Development.

This skill follows the TDD cycle:
1. Red: Design tests from acceptance criteria
2. Green: Build minimal solution that passes
3. Refactor: Improve while staying green

Uses pair collaboration model:
- Creator: Designs tests, implements solution
- Reviewer: Reviews work, validates quality

Requires: Task.md should exist with acceptance criteria.
