description: Define tasks using INVEST method
---

Use the task-definition skill to decompose product requirements into epics and vertical slice tasks.

This skill helps you:
- Review requirements from PRD
- Group functionality into epics
- Slice epics into vertical tasks
- Validate each task against INVEST criteria
- Create Docs/Tasks/Tracking.md and Task.md files

Requires: Docs/Product/PRD.md should exist first.
