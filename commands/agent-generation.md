---
description: Create specialized agents for the product
---

Use the agent-generation skill to create specialized agents based on product needs.

This skill helps you:
- Identify expertise gaps in current agents
- Review product context for specialized needs
- Define agent role and responsibilities
- Configure tools and model
- Generate agent file in `.claude/agents/{agent-name}.md`

Use when existing agents don't cover required domain expertise.

**Important**: Agent files belong in `.claude/agents/`, not in `Docs/`. The `Docs/AGENTS.md` file is for shared protocols, not agent definitions.
